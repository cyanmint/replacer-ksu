Configuration Syntax:
  • %include, /path/to/file.csv - Include another configuration file
  • %include, /path/to/dir/ - Include all CSV files from directory
  • /original/path, /replacement/path - Replace file or directory
  • /path/to/delete, _ - Delete/mask file or directory
  • Lines starting with # are comments
  • Use ${mod_dir} for module directory path
  • Paths ending with / are treated as directories
